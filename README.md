# Dev Interview Simulator

Technical interview simulation platform for software developers.

## Tech Stack
- **Backend:** Java 21, Spring Boot 3.4.x, PostgreSQL 18, Spring Data JPA
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS 4
- **Infrastructure:** Docker, Docker Compose

## Project Structure
- `dev-interview-simulator-backend/`: Spring Boot REST API
- `dev-interview-simulator-frontend/`: React Single Page Application
- `docs/`: Architecture and API documentation
